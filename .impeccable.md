# Design context

Audience: iOS developers evaluating and installing a native Swift package.
Use cases: understand behavior composition, try illustrative interactions, install
through Swift Package Manager and inspect honest coverage/provenance.
User-requested direction: playful interactive behavior demos.
Voice: tactile, curious, clear. Warm paper, cobalt ink, physical colored pieces;
Bricolage Grotesque headlines, native readable controls, no stock product claims.
Keep browser illustrations clearly distinct from native Swift acceptance.
